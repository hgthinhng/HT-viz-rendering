# ESG & Sustainability Analysis

Bài về ESG: materiality, scope emissions, sustainability targets.

## Đặc trưng nội dung
- Multi-dimension scoring (E + S + G axis).
- Peer ESG comparison.
- Materiality matrix (impact x stakeholder concern).
- Trajectory toward 2030/2050 targets.

## Chart families thường dùng

**Profile:**
- `risk_radar` 5-7 axis ESG profile.
- `infographic_panel` ESG score hero.

**Peer comparison:**
- `quadrant_scatter` materiality matrix (impact x stakeholder).
- `dot_plot_distribution` peer ESG score distribution.
- `slopegraph` ESG ranking before/after report.

**Emissions:**
- `waterfall` Scope 1 + 2 + 3 breakdown.
- `line_with_annotations` emissions trajectory với 2030 target line.
- `mechanism_breakdown` value chain emissions.

**Targets & roadmap:**
- `path_progression` Wave 9 net-zero milestones.
- `timeline_horizontal` reporting schedule.

**Cuối:**
- `executive_summary_box`.

## Composition pattern

Mở: ESG profile radar + score hero.
Mid: emissions + materiality.
Cuối: trajectory + commitments.
